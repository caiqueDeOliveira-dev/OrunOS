# Squad Memory: Carousel Campaign

## Estilo de Escrita

- Tom: direto, provocativo, educativo
- Hook: pergunta ou afirmação ousada na primeira linha
- CTA: "Salva para depois" ou "Comenta sua opinião"
- Hashtags: 3-5 relevantes, mistura de niche + broad

## Design Visual

- Paleta: #080000 (bg), #C00018 (destaque), #FFFFFF (texto)
- Fonte: JetBrains Mono para código, Inter para UI
- Layout: carrossel 7-9 slides, primeiro slide = hook visual
- Branding: logo Orun no canto inferior direito

## Estrutura de Conteúdo

1. Slide 1: Hook visual + headline provocativa
2. Slides 2-6: 1 conceito por slide, visual + texto curto
3. Slide 7: Resumo + CTA principal
4. Slide 8: Prova social / caso real (quando aplicável)
5. Slide 9: CTA final + handle

## Proibições Explícitas

- Não prometer resultados que o produto não entrega
- Não usar clickbait enganoso
- Não copiar formato exato de concorrente sem adaptação
- Não exceder 9 slides

## Técnico (específico do squad)

- Formato de saída: Markdown com frontmatter para cada slide
- Imagens: gerar via Fooocus local (prompt detalhado por slide)
- Publicação: Postiz agendado para terça/quinta/domingo 09h/12h/18h
- Métricas alvo: engagement rate > 3.5%, saves > 200
