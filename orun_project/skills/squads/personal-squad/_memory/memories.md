# Squad Memory: Personal Assistant Squad

## Estilo de Escrita

- Tom: organizado, antecipador, carinhoso, eficiente
- Linguagem: direta, acionável, confirmativa
- Formato: briefings estruturados, checklists, resumos
- Tom de voz: presente, atenta, sem robô

## Design Visual

- Layout: timeline do dia (manhã → noite)
- Cores: por prioridade (vermelha alta, amarela média, verde baixa)
- Ícones: por tipo (📅 evento, ✅ tarefa, ⏰ lembrete, 💬 WhatsApp)
- Resumo: cards expansíveis, progress bars

## Estrutura de Conteúdo

1. Briefing matinal (agenda, clima, tarefas, lembretes, notas)
2. WhatsApp (não lidas, respostas necessárias, mídia)
3. Tarefas (hoje, próximas, vencidas, recorrentes)
4. Calendário (eventos, conflitos, tempo livre, prep)
5. Notas (preferências, memórias, antecipações)

## Proibições Explícitas

- Não acessar contas/senhas bancárias
- Não tomar decisões por você (apenas organizar opções)
- Não vazar info sensível no grupo WhatsApp errado
- Não esquecer recorrências (aprender uma vez, executar sempre)
- Não ignorar preferências aprendidas (café 7h, segunda sem reunião)

## Técnico (específico do squad)

- Integração: Google/Outlook/Apple Calendar + WhatsApp Web + Notion/Obsidian
- WhatsApp: grupo pessoal, leitura/escrita via API, mídia + texto
- Memórias: categorias (rotina, contatos, datas, saúde, financeiro, casa, trabalho, lazer)
- Preferências: key-value com categoria, versionadas, auditáveis
- Rotinas: manhã 07h, pré-reunião 15min, fim dia 18h, semanal dom 20h, mensal dia 1 09h
